# 787. Cheapest Flights Within K Stops

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/cheapest-flights-within-k-stops/)  
**Темы:** Graph, Bellman-Ford, DFS, DP

## Описание

Даны `n` городов и рейсы `[from, to, price]` — направленные рёбра. Даны `src`, `dst`, `k` — максимум промежуточных остановок.

Вернуть минимальную стоимость перелёта из `src` в `dst` не более чем с `k` остановками, или `-1`.

**Важно:**
- Путь может быть **дешевле**, но не влезать в лимит остановок
- `k` остановок = **`k+1` рёбер**, отсюда `k+1` проходов Bellman-Ford
- Bellman-Ford требует **копии массива** на каждом проходе: иначе пути «склеиваются» внутри одного прохода
- Дейкстра здесь **не работает** — она жадная и не откатывает решение по числу остановок

## Сложность

- **Время:** `O(k · E)` — `k+1` проходов по всем рёбрам
- **Память:** `O(V)` — два массива расстояний

## Примеры

| n | flights | src | dst | k | Выход |
|---|---|---|---|---|---|
| 4 | `[[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]` | 0 | 3 | 1 | `700` |
| 3 | `[[0,1,100],[1,2,100],[0,2,500]]` | 0 | 2 | 1 | `200` |
| 3 | `[[0,1,100],[1,2,100],[0,2,500]]` | 0 | 2 | 0 | `500` |
| 3 | `[[0,1,100],[1,2,100]]` | 0 | 2 | 0 | `-1` |
| 2 | `[[0,1,300]]` | 0 | 1 | 0 | `300` |
