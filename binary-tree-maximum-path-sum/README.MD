# 124. Binary Tree Maximum Path Sum

**Сложность:** Hard  
**Источник:** [LeetCode](https://leetcode.com/problems/binary-tree-maximum-path-sum/)  
**Темы:** Tree, DFS, Recursion

## Описание

Дано непустое бинарное дерево (обычное, **не** BST). Вернуть максимальную сумму значений узлов по всем возможным непустым путям.

Путь — последовательность узлов, где соседние соединены ребром, каждый узел не более одного раза. Путь не обязан проходить через корень и не обязан заканчиваться в листе.

**Важно:**
- Путь непустой: для `[-3]` ответ `-3`, а не `0`
- Отрицательные узлы можно не брать
- Путь может ветвиться: у него одна вершина и не более двух рукавов

## Алгоритм (post-order DFS)

Рекурсия считает две разные величины:

- **возвращает родителю** — односторонний максимум: `node.val + max(left, right)`
- **обновляет глобально** — разветвлённый кандидат: `node.val + left + right`

Разветвлённый кандидат нельзя вернуть наверх: родитель прицепит его к себе и получит путь с двумя рукавами. Поэтому ответ хранится в поле, а не берётся как `dfs(root)`.

1. **База:** `node == null` → `0`
2. `left = max(0, dfs(node.left))`, `right = max(0, dfs(node.right))` — отрицательную ветку не берём
3. `state = max(state, node.val + left + right)`
4. `return node.val + max(left, right)`

## Визуализация

**Пример 1:** `[-10, 9, 20, null, null, 15, 7]`

```
Вход:       -10
           /    \
          9      20
                /  \
               15   7
       ↓
 9  → вернул  9  | state =  9
15  → вернул 15  | state = 15
 7  → вернул  7  | state = 15
20  → вернул 35  | state = 42   ← 15 + 20 + 7
-10 → вернул 25  | state = 42

Выход: 42 (путь 15 → 20 → 7)
```

**Пример 2:** `[2, -1]`

```
Вход:   2
         \
         -1
       ↓
-1 → вернул -1
 2 → left = 0, right = max(0, -1) = 0
     state = max(-∞, 2 + 0 + 0) = 2
     вернул 2

Выход: 2 — сам узел, а не 2 + (-1) = 1
```

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — стек рекурсии, `h` — высота дерева

## Примеры

| Вход | Выход | Путь |
|------|-------|------|
| `[1,2,3]` | 6 | `2 → 1 → 3` |
| `[-10,9,20,null,null,15,7]` | 42 | `15 → 20 → 7` |
| `[2,-1]` | 2 | `2` |
| `[-3]` | -3 | `-3` |
| `[-2,-1,-3]` | -1 | `-1` |
| `[5,-2,-2]` | 5 | `5` |
