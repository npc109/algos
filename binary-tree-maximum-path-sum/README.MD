# 124. Binary Tree Maximum Path Sum

**Сложность:** Hard  
**Источник:** [LeetCode](https://leetcode.com/problems/binary-tree-maximum-path-sum/)  
**Темы:** Tree, DFS, Recursion

## Описание

Дано бинарное дерево (обычное, **не** BST). Вернуть максимальную сумму значений узлов по всем непустым путям. Путь — связанная последовательность узлов, каждый не более одного раза; он не обязан проходить через корень и заканчиваться в листе.

Рекурсия возвращает наверх односторонний максимум `val + max(0, left, right)`, а ответ копит в поле как разветвлённый кандидат `val + max(0, left) + max(0, right)`.

**Важно:**
- Путь непустой: для `[-3]` ответ `-3`, а не `0`
- Отрицательное поддерево отбрасывается нулём, а не прибавляется целиком
- Разветвлённый кандидат нельзя вернуть наверх — родитель прицепит его к себе, и путь получит три рукава
- Поле-ответ надо сбрасывать в начале каждого вызова, иначе состояние утечёт между тестами

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — стек рекурсии, `h` — высота дерева

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3]` | `6` |
| `[-10,9,20,null,null,15,7]` | `42` |
| `[2,-1]` | `2` |
| `[-3]` | `-3` |
| `[-2,-1,-3]` | `-1` |
| `[5,-2,-2]` | `5` |
