# 496. Next Greater Element I

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/next-greater-element-i/)  
**Темы:** Array, Stack, Monotonic Stack, Hash Table

## Описание

Даны два массива **без повторяющихся элементов**: `nums1` — подмножество `nums2`.

Для каждого `nums1[i]` найти **следующий больший элемент** в `nums2`: первый элемент правее позиции `nums2` с этим значением, который **строго больше** него. Если такого нет — `-1`.

**Важно:**
- Элементы в обоих массивах уникальны
- Ответ идёт в порядке `nums1`, не `nums2`
- Вход мутировать нельзя

## Алгоритм

Один проход по `nums2` с монотонным стеком: в стеке лежат значения, для которых следующий больший ещё не найден (стек убывающий сверху вниз).

Приходит `x`: пока вершина стека меньше `x` — для неё `x` и есть следующий больший, вынимаем и записываем в карту. Затем кладём `x`. Всё, что осталось в стеке в конце, получает `-1`.

Затем проходим по `nums1` и достаём ответы из карты. Карта — `HashMap`, потому что значения произвольные, а не `0..n-1`.

## Сложность

- **Время:** `O(n + m)` — каждый элемент `nums2` кладётся в стек один раз и вынимается не более одного раза, поэтому суммарно работа внутри `while` амортизированно линейна
- **Память:** `O(m)` — стек и карта

## Примеры

| nums1 | nums2 | Выход |
|---|---|---|
| `[4,1,2]` | `[1,3,4,2]` | `[-1,3,-1]` |
| `[2,4]` | `[1,2,3,4]` | `[3,-1]` |
| `[1,3,5,2,4]` | `[6,5,4,3,2,1,7]` | `[7,7,7,7,7]` |
| `[5,4,3,2]` | `[5,4,3,2,1]` | `[-1,-1,-1,-1]` |
| `[]` | `[1,2,3]` | `[]` |
