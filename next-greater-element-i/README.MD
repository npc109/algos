# 496. Next Greater Element I

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/next-greater-element-i/)  
**Темы:** Array, Stack, Monotonic Stack, Hash Table

## Описание

Даны два массива без повторяющихся элементов: `nums1` — подмножество `nums2`. Для каждого `nums1[i]` найти первый элемент правее него в `nums2`, который строго больше, или `-1`.

**Важно:**
- Монотонность **поддерживается**, а не хранится: стек содержит те элементы, для которых ответ ещё не найден
- Приходящий элемент меньше вершины — ложится в стек и ждёт; больше — вынимает всех меньших и даёт им ответ
- Каждый элемент кладётся и вынимается не более одного раза, отсюда `O(n)`
- Без повторяющихся значений в `nums2` можно сопоставлять по значению через `HashMap`

## Сложность

- **Время:** `O(n + m)` — амортизированно линейно
- **Память:** `O(m)` — стек и карта

## Примеры

| nums1 | nums2 | Выход |
|---|---|---|
| `[4,1,2]` | `[1,3,4,2]` | `[-1,3,-1]` |
| `[2,4]` | `[1,2,3,4]` | `[3,-1]` |
| `[1,3,5,2,4]` | `[6,5,4,3,2,1,7]` | `[7,7,7,7,7]` |
| `[5,4,3,2]` | `[5,4,3,2,1]` | `[-1,-1,-1,-1]` |
| `[]` | `[1,2,3]` | `[]` |
