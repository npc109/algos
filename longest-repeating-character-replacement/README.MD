# 424. Longest Repeating Character Replacement

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/longest-repeating-character-replacement/)  
**Темы:** String, Sliding Window, Hash Table

## Описание

Дана строка `s` (заглавные латинские буквы) и число `k`. За одну операцию любую букву можно заменить на любую другую. Вернуть длину самой длинной подстроки, которую можно сделать состоящей из одинаковых букв за **не более чем `k`** замен.

**Важно:**
- Окно `[slow..fast]` длины `L` требует `L - maxFrequency` замен, где `maxFrequency` — частота самого частого символа **в окне**
- Условие «окно ещё влезает»: `maxFrequency + k >= fast - slow + 1`
- `maxFrequency` можно **только накапливать**: она не уменьшается при сдвиге окна. Ответ от этого не страдает, окно лишь смещается, не сужаясь
- `slow` двигается только при нарушении и **всегда вместе с `fast`** — иначе `fast` переобрабатывает тот же символ

## Сложность

- **Время:** `O(n)` — `fast` и `slow` двигаются только вперёд
- **Память:** `O(1)` — карта частот ограничена размером алфавита (26)

## Примеры

| Вход | k | Выход |
|------|---|-------|
| `"ABAB"` | 2 | `4` |
| `"AABABBA"` | 1 | `4` |
| `"AAAA"` | 0 | `4` |
| `"ABCDE"` | 1 | `2` |
| `"ABBB"` | 2 | `4` |
| `"BAAAB"` | 2 | `5` |
| `"ABAAAB"` | 2 | `6` |
| `"ABAB"` | 0 | `1` |
