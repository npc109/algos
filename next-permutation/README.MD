# 31. Next Permutation

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/next-permutation/)  
**Темы:** Array, Two Pointers

## Описание

Дан массив целых чисел. Переставить его в следующую лексикографически большую перестановку **на месте**; если такой нет (массив убывает), вернуть наименьшую — возрастающую.

Алгоритм: справа налево ищем `nums[i] > nums[i-1]` (точка перелома), меняем `nums[i-1]` с самым правым элементом, который его больше, затем разворачиваем хвост после точки перелома.

**Важно:**
- Без точки перелома массив убывает — разворачивается целиком
- Обмен делать с **самым правым** элементом, который больше `nums[bp-1]`: только тогда хвост остаётся невозрастающим и разворот даёт минимальный порядок
- Хвост после перелома в момент обмена всегда невозрастающий — сортировать его не нужно, достаточно развернуть
- Для массива из одного элемента операция ничего не меняет

## Сложность

- **Время:** `O(n)` — два линейных прохода и разворот
- **Память:** `O(1)` — только перестановки на месте

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3]` | `[1,3,2]` |
| `[3,2,1]` | `[1,2,3]` |
| `[1,1,5]` | `[1,5,1]` |
| `[1,3,2]` | `[2,1,3]` |
| `[1]` | `[1]` |
| `[2,3,1]` | `[3,1,2]` |
| `[4,2,0,2,3,2,0]` | `[4,2,0,3,0,2,2]` |
