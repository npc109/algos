# 322. Coin Change

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/coin-change/)  
**Темы:** Array, Dynamic Programming, BFS

## Описание

Даны номиналы монет и сумма `amount`; монет каждого номинала неограниченно много. Вернуть минимальное число монет для набора суммы или `-1`, если набрать её нельзя.

Решение — BFS по суммам: уровень очереди = число использованных монет, первая достигнутая `amount` даёт ответ. `amount == 0` отдаётся сразу — до всех проверок.

**Важно:**
- `amount == 0` — отдельный ранний выход, иначе BFS вернёт `-1` (или монету, «превысившую» сумму)
- Суммы больше `amount` не развиваются и не могут быть ответом
- В `visited` сумму надо добавлять при извлечении: дубли в очереди иначе раздувают её квадратично
- BFS не оптимален по памяти: DP-версия даёт `O(amount)` вместо очереди объёмом `O(amount × coins)`

## Сложность

- **Время:** `O(amount · c)` — до `amount` различных сумм, из каждой до `c` переходов
- **Память:** `O(amount · c)` — очередь и множество посещённых сумм

## Примеры

| Вход | Выход |
|------|-------|
| `coins = [1,2,5], amount = 11` | `3` |
| `coins = [2], amount = 3` | `-1` |
| `coins = [1], amount = 0` | `0` |
| `coins = [1], amount = 1` | `1` |
| `coins = [1,3,4], amount = 6` | `2` |
| `coins = [1,2,5], amount = 100` | `20` |
