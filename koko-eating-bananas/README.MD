# 875. Koko Eating Bananas

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/koko-eating-bananas/)  
**Темы:** Binary Search, Array

## Описание

Даны `piles` — бананов в каждой куче — и `h` часов. За час Коко выбирает одну кучу и съедает из неё не более `k` бананов. Кучу выбирает сам; если в ней меньше `k`, час всё равно тратится целиком, остаток переносится на следующий час.

Вернуть минимальное `k`, при котором все кучи съедаются за `h` часов.

**Важно:**
- Куча на `p` бананов требует `ceil(p / k)` часов; в Java это `(p + k - 1) / k`, а не `p / k`
- Сумма часов набирается в `long`: `10^4` куч × `10^9` бананов не влезает в `int`
- Ищем скорость, а не значение: диапазон ответа — `[1, max(piles)]`, `k = 0` недопустим
- Условие монотонно: если уложился при `k`, уложится и при любом большем

## Сложность

- **Время:** `O(n · log max(piles))` — на каждом шаге бинарного поиска один проход по кучам
- **Память:** `O(1)` — только границы поиска и `long`-счётчик

## Примеры

| Вход | Выход |
|------|-------|
| `piles = [3,6,7,11], h = 8` | `4` |
| `piles = [30,11,23,4,20], h = 5` | `30` |
| `piles = [30,11,23,4,20], h = 6` | `23` |
| `piles = [3,7,5], h = 3` | `7` |
| `piles = [805306368,805306368,805306368], h = 1000000000` | `3` |
