# 207. Course Schedule

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/course-schedule/)  
**Темы:** Graph, DFS, BFS, Topological Sort

## Описание

Всего `numCourses` курсов. Пара `prerequisites[i] = [a, b]` означает, что для курса `a` нужно сначала пройти `b`. Вернуть `true`, если можно пройти все курсы.

**Важно:**
- Ответ `false` тогда и только тогда, когда в графе зависимостей есть цикл
- Самозависимость `[a, a]` — тоже цикл

## Сложность

- **Время:** `O(V + E)` — каждая вершина обходится один раз
- **Память:** `O(V + E)` — список смежности и состояния вершин

## Примеры

| numCourses | prerequisites | Выход |
|---|---|---|
| 2 | `[[1,0]]` | true |
| 2 | `[[1,0],[0,1]]` | false |
| 3 | `[[0,1],[1,2],[2,0]]` | false |
| 5 | `[[1,4],[2,4],[3,1],[3,2]]` | true |
| 1 | `[]` | true |
| 1 | `[[0,0]]` | false |
| 4 | `[[2,0],[2,1],[3,0],[3,1]]` | true |
