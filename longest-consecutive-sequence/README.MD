# 128. Longest Consecutive Sequence

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/longest-consecutive-sequence/)  
**Темы:** Array, Hash Set

## Описание

Дан неупорядоченный массив целых чисел (возможны дубликаты). Вернуть длину самой длинной последовательности идущих подряд значений, например `1,2,3,4`.

Все числа кладутся в `HashSet`; для элемента, у которого нет `el - 1`, цепочка `el + 1`, `el + 2`, ... считается до обрыва. Максимум длин — ответ.

**Важно:**
- Признак начала цепочки — отсутствие `el - 1` в множестве: без этой проверки каждая внутренняя цепочка считалась бы заново, и сложность стала бы `O(n²)`
- Порядок в исходном массиве роли не играет, значения должны быть подряд идущими
- Дубликаты схлопываются множеством и длину не увеличивают
- Переполнение `el + 1` на `Integer.MAX_VALUE` стороной LeetCode не проверяется, но в общем случае нужно `long`

## Сложность

- **Время:** `O(n)` — каждый элемент обрабатывается один раз: добавление и продление считается только из начала цепочки
- **Память:** `O(n)` — множество всех чисел

## Примеры

| Вход | Выход |
|------|-------|
| `[100,4,200,1,3,2]` | `4` |
| `[0,3,7,2,5,8,4,6,0,1]` | `9` |
| `[]` | `0` |
| `[1]` | `1` |
| `[1,2,0,1]` | `3` |
