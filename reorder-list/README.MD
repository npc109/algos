# 143. Reorder List

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/reorder-list/)  
**Темы:** Linked List, Two Pointers, Fast & Slow Pointers

## Описание

Дан односвязный список `L0 → L1 → ... → Ln`. Перестроить его на месте в порядок `L0 → Ln → L1 → Ln-1 → L2 → ...`.

Три шага: найти середину быстрым и медленным указателями, развернуть вторую половину, слить половины вперемешку.

**Важно:**
- Меняются ссылки `next`, а не значения `val` — при плоском списке это не различить, но копирование значений не проходит проверку узлов
- После поиска середины `slow.next` обнуляется, иначе слияние зациклится на хвосте
- Во второй половине на один узел меньше только при нечётной длине — при слиянии её указатель может стать `null` раньше; нужен проверочный тернарник
- Список из одного узла и из двух возвращается как есть

## Сложность

- **Время:** `O(n)` — поиск середины, разворот и слияние — три линейных прохода
- **Память:** `O(1)` — только указатели, список меняется на месте

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,4,5]` | `[1,5,2,4,3]` |
| `[1,2,3,4]` | `[1,4,2,3]` |
| `[1,2,3,4,5,6]` | `[1,6,2,5,3,4]` |
| `[1]` | `[1]` |
| `[1,2]` | `[1,2]` |
