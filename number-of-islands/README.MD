# 200. Number of Islands

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/number-of-islands/)  
**Темы:** Array, Matrix, DFS, BFS

## Описание

Дана матрица `grid` из `'1'` (суша) и `'0'` (вода). Вернуть количество островов.

Остров — группа клеток `'1'`, соединённых по горизонтали или вертикали.

**Важно:**
- По диагонали связности нет
- Метод изменяет входную матрицу, затирая посещённые клетки

## Сложность

- **Время:** `O(m · n)` — каждая клетка обрабатывается один раз
- **Память:** `O(m · n)` — стек рекурсии в худшем случае

## Примеры

| Вход | Выход |
|------|-------|
| `11000 / 11000 / 00100 / 00011` | 3 |
| `11110 / 11010 / 11000 / 00000` | 1 |
| `111 / 010 / 111` | 1 |
| `10 / 01` | 2 |
| `11 / 11` | 1 |
| `0` | 0 |
