# 98. Validate Binary Search Tree

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/validate-binary-search-tree/)  
**Темы:** Tree, DFS, Binary Search Tree

## Описание

Дан корень бинарного дерева. Вернуть `true`, если это корректное BST: для каждого узла все значения слева строго меньше, все справа строго больше.

**Важно:**
- Локального сравнения с детьми **недостаточно** — нарушение может прийти от дальнего предка
- Нужен диапазон `(min, max)`, который сужается при спуске: влево — верхняя граница, вправо — нижняя
- Неравенство **строгое**, дубликаты запрещены
- `Integer.MIN_VALUE`/`MAX_VALUE` как границы корня **ломаются** на входе `[Integer.MIN_VALUE]` — нужен `long` или `null` вместо границ

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — стек рекурсии; `O(n)` в худшем случае (вырожденное дерево)

## Примеры

| Вход | Выход |
|---|---|
| `[2,1,3]` | `true` |
| `[5,1,4,null,null,3,6]` | `false` |
| `[2,1,3,null,null,0,4]` | `false` |
| `[]` | `true` |
| `[Integer.MIN_VALUE]` | `true` |
| `[2,2,2]` | `false` |
