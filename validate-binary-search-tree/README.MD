# 98. Validate Binary Search Tree

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/validate-binary-search-tree/)  
**Темы:** Tree, DFS, Binary Search Tree

## Описание

Дан корень бинарного дерева. Вернуть `true`, если это корректное BST: для **каждого** узла все значения слева **строго меньше** `node.val`, все справа — **строго больше**.

- Неравенство строгое — дубликаты запрещены
- `null`-корень валиден
- Локального сравнения с детьми **недостаточно**

## Почему локальной проверки мало

```
     5
    / \
   1   4
      / \
     3   6
```

`1<5` ✓, `4>5` ✓, `3<4` ✓, `6>4` ✓ — все локальные проверки проходят. Но `3` лежит в правом поддереве `5`, а `3 < 5`. Нарушение всегда приходит от **дальнего предка**, не от родителя.

## Алгоритм

Спускаемся с диапазоном `(min, max)`, который сужается: влево — верхняя граница становится `node.val`, вправо — нижняя. Узел валиден, если строго внутри. У корня диапазон неограничен.

**Ловушка с границами.** Если у корня поставить `Integer.MIN_VALUE`/`MAX_VALUE`, то на входе `[Integer.MIN_VALUE]` проверка `min < node.val` даст `MIN_VALUE < MIN_VALUE` = `false`, и валидное дерево будет отвергнуто. Решения: `long`, `null` как «границы нет», или in-order.

**Альтернатива — in-order.** In-order обход даёт отсортированную последовательность, достаточно проверять `node.val > prev`. `prev` тоже `Integer` с `null`, иначе та же ловушка.

## Реализация

Две перегрузки `dfs`: рабочая `(node, min, max)` и точка входа `(root)`, которая не проверяет корень (он без ограничений) и сразу идёт в детей.

```java
private boolean dfs(TreeNode node, Integer min, Integer max) {
    if (node == null) return true;
    if ((min == null || min < node.val) && (max == null || node.val < max)) {
        return dfs(node.left, min, node.val) && dfs(node.right, node.val, max);
    }
    return false;
}
```

Возможное упрощение: убрать `dfs(root)` и вызывать `dfs(root, null, null)` — одна функция вместо двух, семантика границ однородна.

## Ошибки при решении

| Ошибка | Причина |
|---|---|
| `NullPointerException` на пустом дереве | `dfs(root)` обращался к `root.left` без проверки на `null` |
| Две почти одинаковые функции | границы проверялись несимметрично: в одной `min == null`, в другой `max == null` |

Проверять обе границы одинаково через `(x == null || ...)` — дублирование исчезает само.

## Сложность

- **Время:** `O(n)` — каждый узел один раз
- **Память:** `O(h)` — стек рекурсии; `O(n)` в худшем случае (вырожденное дерево)

## Примеры

| Вход | Выход |
|---|---|
| `[2,1,3]` | `true` |
| `[5,1,4,null,null,3,6]` | `false` |
| `[2,1,3,null,null,0,4]` | `false` |
| `[]` | `true` |
| `[Integer.MIN_VALUE]` | `true` |
| `[2,2,2]` | `false` |
