# 11. Container With Most Water

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/container-with-most-water/)  
**Темы:** Array, Two Pointers, Greedy

## Описание

Дан массив `height`: каждая пара линий вместе с осью X образует контейнер. Вернуть максимальную площадь такого контейнера — `min(height[l], height[r]) × (r - l)`.

Два указателя с краёв: считаем площадь и сдвигаем внутрь ту сторону, что ниже, пока `l < r`.

**Важно:**
- Сдвигать нужно **более низкий** указатель: перемещение высокого только уменьшит ширину и не поднимет высоту
- При равных высотах площадь не упадёт от сдвига любого — код сдвигает `r`
- Контейнер не наклоняется, линия учитывается целиком — до нулевой отметки
- Нужен максимум по всем парам, а не площадь текущего положения

## Сложность

- **Время:** `O(n)` — указатели сближаются, каждая итерация сдвигает один из них
- **Память:** `O(1)` — только `l`, `r` и текущий максимум

## Примеры

| Вход | Выход |
|------|-------|
| `[1,8,6,2,5,4,8,3,7]` | `49` |
| `[1,1]` | `1` |
| `[4,3,2,1,4]` | `16` |
| `[1,2,1]` | `2` |
