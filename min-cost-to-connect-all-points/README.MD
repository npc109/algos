# 1584. Min Cost to Connect All Points

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/min-cost-to-connect-all-points/)  
**Темы:** Graph, MST, Union-Find, Prim, Kruskal

## Описание

Даны точки на плоскости. Стоимость соединения двух точек — манхэттенское расстояние `|xi-xj| + |yi-yj|`. Вернуть минимальную суммарную стоимость, чтобы все точки были связаны.

Задача о минимальном остовном дереве (MST).

**Важно:**
- В MST ровно `n-1` рёбер; при большем числе появится цикл
- Граф неявный: рёбер не дано, каждая пара точек — потенциальное ребро, всего `n(n-1)/2`
- **Краскал:** сортировка всех рёбер + Union-Find, память `O(n²)`
- **Прим:** `PriorityQueue`, рёбра считаются на лету, память `O(n)`
- В Приме в очередь кладётся **вес ребра**, а не накопленное расстояние (отличие от Дейкстры)

## Сложность

- **Время:** `O(n² log n)` — доминирует сортировка (Краскал) или куча (Прим)
- **Память:** `O(n²)` для Краскала, `O(n)` для Прима

## Примеры

| points | Выход |
|---|---|
| `[[0,0],[2,2],[3,10],[5,2],[7,0]]` | `20` |
| `[[3,12],[-2,5],[-4,1]]` | `18` |
| `[[0,0]]` | `0` |
| `[[0,0],[3,4]]` | `7` |
| `[[0,0],[1,0],[2,0],[3,0]]` | `3` |
