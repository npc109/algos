# 300. Longest Increasing Subsequence

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/longest-increasing-subsequence/)  
**Темы:** Array, Dynamic Programming

## Описание

Дан массив целых чисел. Вернуть длину самой длинной **строго возрастающей** подпоследовательности.

`search(ind)` — длина НВП, заканчивающейся на `ind`: перебираются все `i <= ind` с `nums[ind] > nums[i]`, берётся `1 + search(i)`; если таких нет — `1`. Ответ — максимум по всем индексам, значения кэшируются в `r[ind]`.

**Важно:**
- Возрастание строгое: равные элементы цепочку не продолжают — нужно `>` , а не `>=`
- Подпоследовательность не непрерывна, элементы можно пропускать
- Нужна только длина; сама НВП не восстанавливается
- Пустой массив даёт `0` — отдельная проверка до рекурсии
- `O(n log n)`-версия («patience sorting») здесь не используется: она требует `tails`, а этот код — `O(n²)`

## Сложность

- **Время:** `O(n²)` — каждый индекс считается один раз, внутри перебор всех предыдущих
- **Память:** `O(n)` — таблица `r` и глубина рекурсии

## Примеры

| Вход | Выход |
|------|-------|
| `[10,9,2,5,3,7,101,18]` | `4` |
| `[0,1,0,3,2,3]` | `4` |
| `[7,7,7,7]` | `1` |
| `[1]` | `1` |
| `[]` | `0` |
