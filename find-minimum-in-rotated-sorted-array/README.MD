# 153. Find Minimum in Rotated Sorted Array

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)  
**Темы:** Array, Binary Search

## Описание

Дан отсортированный по возрастанию массив уникальных чисел, повёрнутый на несколько позиций. Вернуть минимальный элемент за `O(log n)`.

Рекурсивный бинарный поиск на отрезке `[start, stop]`: если `a[start] <= a[stop]`, отрезок отсортирован и минимум в `start`; иначе идём в `[mid, stop]` при `a[mid] >= a[stop]` и в `[start, mid]` при `a[mid] < a[start]`.

**Важно:**
- `a[mid]` может совпасть с границами (`a[mid] >= a[stop]`, затем `a[mid] < a[start]`); при трёх элементах `start == mid`, поэтому нужны оба условия подряд, иначе — бесконечная рекурсия
- Округление `mid` вверх `Math.ceil` обязательно: при `a[start] > a[stop]` и `mid == start` левая ветка не сузит отрезок
- `mid` считать как `start + (stop - start) / 2`, чтобы не переполнить `int`
- Массив уникален: с дубликатами ветвление по `a[mid]` неоднозначно и нужен `O(n)`-вариант

## Сложность

- **Время:** `O(log n)` — отрезок поиска каждый раз уменьшается
- **Память:** `O(log n)` — стек рекурсии по числу делений

## Примеры

| Вход | Выход |
|------|-------|
| `[4,5,6,7,0,1,2]` | `0` |
| `[0,1,2,3,4]` | `0` |
| `[3,1,2]` | `1` |
| `[10,11,12,13,14,15,16,17,1,2,3]` | `1` |
| `[2147483647,-2147483648]` | `-2147483648` |
| `[3,4,5,1,2]` | `1` |
