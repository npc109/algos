# 153. Find Minimum in Rotated Sorted Array

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)  
**Темы:** Array, Binary Search

## Описание

Дан отсортированный по возрастанию массив уникальных целых чисел, повёрнутый на некоторое количество позиций. Найти минимальный элемент за O(log n).

**Важно:**
- Дубликатов в массиве нет
- Результат — минимальный элемент (как на LeetCode)

## Алгоритм (Бинарный поиск)

Рекурсивный бинарный поиск:

1. **Базовый случай:** Если `a[start] <= a[stop]` — массив отсортирован, минимум в `start`
2. **Рекурсивный шаг:**
   - Находим `mid`
   - Если `a[mid] >= a[stop]` — минимум правее → ищем в `[mid, stop]`
   - Если `a[mid] < a[start]` — минимум левее → ищем в `[start, mid]`

## Визуализация

**Пример 1:**
```
Вход:  [4, 5, 6, 7, 0, 1, 2]
        ↓
       start=0, stop=6, mid=3
       a[mid]=7 >= a[stop]=2 → ищем справа
        ↓
       start=3, stop=6, mid=4
       a[mid]=0 < a[start]=4 → ищем слева
        ↓
       start=3, stop=4, mid=3
       a[mid]=7 >= a[stop]=0 → ищем справа
        ↓
       start=4, stop=4 → a[start]=0, минимум найден!

Выход: 0
```

**Пример 2:**
```
Вход:  [3, 1, 2]
        ↓
       start=0, stop=2, mid=1
       a[mid]=1 < a[start]=3 → ищем слева
        ↓
       start=0, stop=1, mid=0
       a[mid]=3 >= a[stop]=1 → ищем справа
        ↓
       start=1, stop=1 → a[start]=1, минимум найден!

Выход: 1
```

## Примеры

| Вход | Выход |
|------|-------|
| `[4,5,6,7,0,1,2]` | 0 |
| `[0,1,2,3,4]` | 0 |
| `[3,1,2]` | 1 |
| `[10,11,12,13,14,15,16,17,1,2,3]` | 1 |
| `[Integer.MAX_VALUE, Integer.MIN_VALUE]` | Integer.MIN_VALUE |
| `[3,4,5,1,2]` | 1 |
