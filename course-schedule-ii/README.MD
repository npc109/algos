# 210. Course Schedule II

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/course-schedule-ii/)  
**Темы:** Graph, DFS, BFS, Topological Sort

## Описание

Всего `numCourses` курсов. Пара `prerequisites[i] = [a, b]` означает, что для курса `a` нужно сначала пройти `b`. Вернуть порядок прохождения всех курсов, или пустой массив, если это невозможно.

**Важно:**
- Валидных порядков может быть несколько — принимается любой
- Пустой массив возвращается тогда и только тогда, когда в графе зависимостей есть цикл
- Рёбра строятся от зависимого курса к его предусловию, поэтому post-order даёт готовый порядок без разворота

## Сложность

- **Время:** `O(V + E)` — каждая вершина обходится один раз
- **Память:** `O(V + E)` — список смежности и состояния вершин

## Примеры

| numCourses | prerequisites | Выход |
|---|---|---|
| 2 | `[[1,0]]` | `[0,1]` |
| 4 | `[[1,0],[2,0],[3,1],[3,2]]` | `[0,1,2,3]` (или другой валидный) |
| 1 | `[]` | `[0]` |
| 2 | `[[1,0],[0,1]]` | `[]` |
| 1 | `[[0,0]]` | `[]` |
