# 167. Two Sum II - Input Array Is Sorted

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)  
**Темы:** Array, Two Pointers, Binary Search

## Описание

Дан отсортированный по возрастанию массив `numbers` и число `target`. Вернуть **1-indexed** индексы пары элементов, дающих в сумме `target`.

Два указателя: `l` на начале, `r` на конце. Если сумма больше `target` — уменьшаем `r`, меньше — увеличиваем `l`.

**Важно:**
- Индексы в ответе **1-indexed**, пара — `[l+1, r+1]`, и идут по возрастанию
- Гарантируется ровно одно решение, поэтому проверять отсутствие не нужно
- Цикл живёт на `l < r`: индекс сам с собой не спаривается, один элемент дважды не используется
- Сумму считать в `long` — `numbers[l] + numbers[r]` на краях `int` переполняется
- Хеш-таблица не нужна — отсортированность даёт два указателя за `O(n)`

## Сложность

- **Время:** `O(n)` — указатели сближаются, каждый шаг сдвигает один из них
- **Память:** `O(1)` — только два указателя

## Примеры

| Вход | Выход |
|------|-------|
| `numbers = [2,7,11,15], target = 9` | `[1,2]` |
| `numbers = [2,3,4], target = 6` | `[1,3]` |
| `numbers = [-1,0], target = -1` | `[1,2]` |
| `numbers = [1,2,3,4,4,9,56,90], target = 8` | `[4,5]` |
