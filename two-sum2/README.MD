# 167. Two Sum II - Input Array Is Sorted

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)  
**Темы:** Array, Two Pointers, Binary Search

## Описание

Дан отсортированный по возрастанию массив целых чисел и число `target`. Необходимо найти два индекса, такие что соответствующие элементы в сумме дают `target`.

**Важно:**
- Ответ должен содержать индексы (1-indexed), отсортированные по возрастанию
- Гарантируется, что ровно одно решение существует
- Нельзя использовать один и тот же элемент дважды

## Алгоритм (Two Pointers)

Используем два указателя — на начало и конец массива:

1. **Инициализация:** `l = 0`, `r = length - 1`
2. **Цикл** пока `l < r`:
   - Вычисляем сумму `s = numbers[l] + numbers[r]`
   - Если `s == target` — нашли, возвращаем `[l+1, r+1]` (1-indexed)
   - Если `s < target` — нужно увеличить сумму, сдвигаем `l` вправо
   - Если `s > target` — нужно уменьшить сумму, сдвигаем `r` влево

## Визуализация

**Пример 1:**
```
Вход:  numbers = [2, 7, 11, 15], target = 9
       ↓
Шаг 1: l=0, r=3 → 2 + 15 = 17 > 9 → r--
Шаг 2: l=0, r=2 → 2 + 11 = 13 > 9 → r--
Шаг 3: l=0, r=1 → 2 + 7 = 9 == 9 → нашли!

Выход: [1, 2]
```

**Пример 2:**
```
Вход:  numbers = [2, 3, 4], target = 6
       ↓
Шаг 1: l=0, r=2 → 2 + 4 = 6 == 6 → нашли!

Выход: [1, 3]
```

**Пример 3:**
```
Вход:  numbers = [-1, 0], target = -1
       ↓
Шаг 1: l=0, r=1 → -1 + 0 = -1 == -1 → нашли!

Выход: [1, 2]
```

## Примеры

| Вход (numbers) | Вход (target) | Выход | Пояснение |
|----------------|---------------|-------|-----------|
| `[2,7,11,15]` | 9 | `[1,2]` | 2 + 7 = 9 |
| `[2,3,4]` | 6 | `[1,3]` | 2 + 4 = 6 |
| `[-1,0]` | -1 | `[1,2]` | -1 + 0 = -1 |
| `[1,2,3,4,4,9,56,90]` | 8 | `[4,5]` | 4 + 4 = 8 |
