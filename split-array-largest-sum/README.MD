# 410. Split Array Largest Sum

**Сложность:** Hard  
**Источник:** [LeetCode](https://leetcode.com/problems/split-array-largest-sum/)  
**Темы:** Binary Search, Array, Dynamic Programming

## Описание

Дан массив `nums` из неотрицательных чисел и число `k`. Разбить массив на `k` **непрерывных** подмассивов так, чтобы максимальная сумма по подмассивам была минимальной. Вернуть эту минимальную возможную максимальную сумму.

**Важно:**
- Подмассивы непрерывные: `nums` **нельзя** сортировать и нельзя переставлять
- `k` отрезков — это «**не больше** `k`»: если жадный проход дал меньше отрезков, потолок годится, а лишние разбиения можно получить дорезанием без роста максимума
- Диапазон поиска: `max(nums) <= ответ <= sum(nums)`. Ниже `max(nums)` — элемент не влезает никуда, на `sum(nums)` — всегда один отрезок
- Проверка «годится ли потолок»: набирать сумму слева направо, при превышении закрывать отрезок и начинать новый
- Сумма набирается в `long` при обобщении: `10^3` элементов по `10^6` дают `10^9` — в `int` влезает, но запас меньше чем в 2 раза
- `nums[i] = 0` допустим: ответ может быть `0`, тогда `l == r == 0` и цикл не выполняется ни разу

## Сложность

- **Время:** `O(n · log(sum(nums)))` — на каждом шаге бинарного поиска один проход по массиву
- **Память:** `O(1)` — только границы поиска и счётчик отрезков

## Примеры

| Вход | Выход |
|------|-------|
| `nums = [7,2,5,10,8], k = 2` | `18` |
| `nums = [1,2,3,4,5], k = 2` | `9` |
| `nums = [1,4,4], k = 3` | `4` |
| `nums = [7,2,5,10,8], k = 1` | `32` |
| `nums = [7,2,5,10,8], k = 5` | `10` |
| `nums = [0,0,0], k = 3` | `0` |
