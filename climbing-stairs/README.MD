# 70. Climbing Stairs

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/climbing-stairs/)  
**Темы:** Dynamic Programming, Math, Memoization

## Описание

До вершины `n` ступенек. За шаг можно подняться на `1` или `2` ступеньки. Вернуть число различных способов добраться до вершины.

**Важно:**
- Это `F(n+1)`, где `F` — числа Фибоначчи: до ступеньки `k` попадают только с `k-1` (шаг `1`) или `k-2` (шаг `2`), множества не пересекаются
- Инвариант двух переменных: перед итерацией `i` в `cur` лежит `f(i)`, в `prev` лежит `f(i-1)`, где `f(0) = 1` («стоять на месте» — один способ)
- `n <= 45` задано не случайно: `f(45) = 1 836 311 903` влезает в `int`, `f(46)` уже нет
- Ответ не зависит от `n=0`: у задачи `n >= 1`, но `f(0) = 1` нужен как база инварианта

## Сложность

- **Время:** `O(n)` — `n` итераций цикла
- **Память:** `O(1)` — две переменные, массив `dp` не нужен: используются только два последних значения

## Примеры

| Вход | Выход |
|------|-------|
| `n = 1` | `1` |
| `n = 2` | `2` |
| `n = 3` | `3` |
| `n = 5` | `8` |
| `n = 44` | `1134903170` |
| `n = 45` | `1836311903` |
