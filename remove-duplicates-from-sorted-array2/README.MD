# 80. Remove Duplicates from Sorted Array II

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/)  
**Темы:** Array, Two Pointers

## Описание

Дан отсортированный массив. Убрать дубликаты **на месте** так, чтобы каждое значение встречалось не более двух раз. Вернуть `k` — новую длину; первые `k` элементов массива должны содержать результат.

Два указателя: `w` — куда писать, `r` — что читаем. Элемент `nums[r]` записывается, если он отличается от `nums[w-2]`.

**Важно:**
- Сравнивать нужно с `nums[w - 2]` — элементом, записанным **двумя позициями раньше**, а не с текущим читаемым `nums[r-1]`
- Первые два элемента остаются всегда, поэтому `w` и `r` стартуют с `2`
- Хвост массива после `k` не важен — тесты и LeetCode смотрят только первые `k` элементов
- Пустой массив или из одного элемента — цикл просто не выполнится, вернётся длина массива

## Сложность

- **Время:** `O(n)` — один проход по массиву
- **Память:** `O(1)` — только два индекса

## Примеры

| Вход | Выход |
|------|-------|
| `[1,1,1,2,2,3]` | `5`, первые 5 — `[1,1,2,2,3]` |
| `[0,0,1,1,1,1,2,3,3]` | `7`, первые 7 — `[0,0,1,1,2,3,3]` |
| `[-1,0,0,0,0,3,3]` | `5`, первые 5 — `[-1,0,0,3,3]` |
| `[5,5,5,5,5]` | `2`, первые 2 — `[5,5]` |
| `[1,2,3]` | `3` |
