# 133. Clone Graph

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/clone-graph/)  
**Темы:** Hash Table, Graph, DFS, BFS

## Описание

Дан узел неориентированного связного графа: `val` и список соседей `neighbors`. Вернуть **глубокую копию** графа. Вход задаётся списком смежности `adj`, где `adj[i]` — соседи узла `i+1`; `null` означает пустой граф.

DFS с `HashMap` «значение → клон»: узел кладётся в мапу **до** обхода соседей, поэтому цикл обрывается на уже склонированном узле.

**Важно:**
- Граф содержит циклы — без мапы обход уйдёт в бесконечную рекурсию
- Регистрировать клон надо **до** рекурсии по соседям, иначе узел из цикла склонируется повторно
- Клон не должен ссылаться на оригинальные узлы
- Пустой граф (`null`) → `null`

## Сложность

- **Время:** `O(V + E)` — каждый узел и каждое ребро обрабатываются один раз
- **Память:** `O(V)` — мапа клонов и стек рекурсии

## Примеры

| Вход | Выход |
|------|-------|
| `[[2,4],[1,3],[2,4],[1,3]]` | `[[2,4],[1,3],[2,4],[1,3]]` |
| `[[]]` | `[[]]` |
| `[[2],[1]]` | `[[2],[1]]` |
| `[[2,3],[1,3],[1,3]]` | `[[2,3],[1,3],[1,3]]` |
| `[]` | `null` |
