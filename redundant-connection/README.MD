# 684. Redundant Connection

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/redundant-connection/)  
**Темы:** Graph, Union-Find, DFS, BFS

## Описание

Дан граф, который получился из дерева добавлением одного ребра. Вернуть ребро, удаление которого снова делает граф деревом. Если подходящих несколько, вернуть то, которое встречается последним во входном массиве.

**Важно:**
- Вершины нумеруются с `1`
- Ограничение `ai < bi <= edges.length` — то есть вершин ровно `edges.length`
- Цикл в графе ровно один, поэтому ответ определён однозначно

## Сложность

- **Время:** `O(E · α(V))` — со сжатием путей и объединением по размеру; без оптимизаций `O(E · V)`
- **Память:** `O(V)`

## Примеры

| edges | Выход |
|---|---|
| `[[1,2],[1,3],[2,3]]` | `[2,3]` |
| `[[1,2],[2,3],[3,4],[1,4],[1,5]]` | `[1,4]` |
| `[[2,3],[1,2],[1,3]]` | `[1,3]` |
| `[[1,2],[2,3],[3,4],[4,2]]` | `[4,2]` |
| `[[1,2],[2,3],[3,4],[4,5],[5,1]]` | `[5,1]` |
