# 494. Target Sum

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/target-sum/)  
**Темы:** Array, Dynamic Programming, Backtracking, Memoization

## Описание

Дан `nums` и `target`. К каждому элементу приписать знак `+` или `-`. Вернуть число выражений, равных `target`.

**Важно:**
- Состояние мемоизации — пара `(start, currentSum)`: разные ветви приходят в одну пару, и её результат переиспользуется
- `memo.get(k) != null` — корректный признак «посчитано», потому что число способов всегда `>= 0`
- `ArrayList<Integer>` как ключ `HashMap` работает: `List` переопределяет `equals`/`hashCode` по содержимому. `int[]` не работает — сравнение по ссылке
- Сведение к knapsack: если `P` — сумма со знаком `+`, `M` — со знаком `-`, то `P - M = target` и `P + M = sum`, значит `P = (sum + target) / 2`. Тогда задача — число способов набрать `P`
- Для knapsack-варианта: если `sum + target` нечётное или `target > sum` / `target < -sum`, ответ `0`
- `nums[i] = 0` даёт **два** способа на каждый нулевой элемент (`+0` и `-0`)
- Счётчик может достигать `2^20 ≈ 10^6` — влезает в `int`

## Сложность

- **Время:** `O(n · sum)` — число состояний `(start, currentSum)`, `sum = sum(nums) <= 20000`
- **Память:** `O(n · sum)` — таблица кэша; без мемоизации время `O(2^n)`
- **Knapsack-вариант:** `O(n · target')` по времени, `O(target')` по памяти

## Примеры

| Вход | Выход |
|------|-------|
| `nums = [1,1,1,1,1], target = 3` | `5` |
| `nums = [1], target = 1` | `1` |
| `nums = [1], target = 2` | `0` |
| `nums = [0], target = 0` | `2` — `+0` и `-0` |
| `nums = [0,0,0,0,0], target = 0` | `32` — все `2^5` |
| `nums = [1,2,3], target = 0` | `2` |
