# 543. Diameter of Binary Tree

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/diameter-of-binary-tree/)  
**Темы:** Tree, DFS, Binary Tree

## Описание

Дан корень бинарного дерева. Вернуть диаметр — длину самого длинного пути между любыми двумя узлами; путь не обязан проходить через корень.

Post-order DFS: `dfs` возвращает высоту поддерева, а глобальный максимум обновляется кандидатом `left + right` — путём, у которого текущий узел вершина.

**Важно:**
- Длина считается в **рёбрах**, а не в узлах: для одного узла диаметр `0`
- Ответ — не всегда путь через корень: лучший путь может лежать целиком в поддереве
- Наверх уходит `1 + max(left, right)`, а не `left + right` — иначе получится путь с двумя рукавами
- Поле-максимум сбрасывается в начале вызова, иначе значение утечёт между тестами

## Сложность

- **Время:** `O(n)` — каждый узел обрабатывается один раз
- **Память:** `O(h)` — стек рекурсии, `h` — высота дерева

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,4,5]` | `3` |
| `[1,2]` | `1` |
| `[1]` | `0` |
| `[1,2,3]` | `2` |
| `[1,2,3,4,5,null,null,6]` | `4` |
| `[1,3,2,5,4]` | `3` |
