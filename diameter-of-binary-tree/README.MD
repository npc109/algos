# 543. Diameter of Binary Tree

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/diameter-of-binary-tree/)  
**Темы:** Tree, DFS, Binary Tree

## Описание

Дан корень бинарного дерева. Вернуть **диаметр** — длину самого длинного пути между любыми двумя узлами. Путь не обязан проходить через корень.

**Важно:**
- Длина считается в **рёбрах**, а не в узлах
- Для одного узла диаметр равен `0`
- Каждый узел может быть «вершиной» пути: путь проходит через него, уходя в левое и правое поддеревья

## Алгоритм (post-order DFS)

`dfs(node)` возвращает **высоту** поддерева в рёбрах, попутно обновляя глобальный максимум.

Для узла: `left` и `right` — высоты поддеревьев. Путь, у которого этот узел является вершиной, состоит из `left + right` рёбер — это кандидат в ответ. Наверх возвращается `1 + max(left, right)`.

Каждый узел посещается один раз, поэтому один проход даёт ответ.

## Сложность

- **Время:** `O(n)` — каждая вершина обрабатывается один раз
- **Память:** `O(h)` — стек рекурсии, `h` — высота дерева

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,4,5]` | 3 |
| `[1,2]` | 1 |
| `[1]` | 0 |
| `[1,2,3]` | 2 |
| `[1,2,3,4,5,null,null,6]` | 4 |
| `[1,3,2,5,4]` | 3 |
