# 5. Longest Palindromic Substring

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/longest-palindromic-substring/)  
**Темы:** String, Dynamic Programming

## Описание

Дана строка `s`. Вернуть самую длинную подстроку-палиндром.

**Важно:**
- Состояние: `dp[i][j]` — является ли `s[i..j]` палиндромом
- Переход: `s[i] == s[j] && dp[i + 1][j - 1]` — **внутренний** отрезок, поэтому `i + 1`, а не `i - 1`
- Порядок заполнения: внешний цикл **по длине** `len`, иначе `dp[i+1][j-1]` не посчитана к моменту `dp[i][j]`
- База: длина 1 — все `true`; длина 2 — только `s[i] == s[j]`, потому что `dp[i+1][i]` — пустой отрезок
- Ответ **не однозначен** (`babad` → `aba` или `bab`), поэтому тесты проверяют длину и палиндромность, а не конкретную строку
- `dp[l][r] = true` обязано выполняться во всех случаях, когда палиндром найден: без него следующая длина читает `false`

## Сложность

- **Время:** `O(n²)` — `n²/2` отрезков, каждый проверяется за `O(1)`
- **Память:** `O(n²)` — `boolean[n][n]`; заполняется только верхний треугольник (`j >= i`)
- **Альтернатива:** расширение от центра за `O(n²)` времени и `O(1)` памяти

## Примеры

| Вход | Выход |
|------|-------|
| `s = "babad"` | `"bab"` или `"aba"` |
| `s = "cbbd"` | `"bb"` |
| `s = "a"` | `"a"` |
| `s = "abcba"` | `"abcba"` |
| `s = "aaabaaaa"` | `"aaabaaa"` |
| `s = "forgeeksskeegfor"` | `"geeksskeeg"` |
