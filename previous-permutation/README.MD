# 1053. Previous Permutation With One Swap

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/previous-permutation-with-one-swap/)  
**Темы:** Array, Greedy

## Описание

Дан массив чисел. Ровно одним обменом двух элементов получить лексикографически наибольшую перестановку, которая меньше исходной. Если это невозможно, вернуть массив без изменений.

Идём справа налево до первой позиции `arr[i] > arr[i+1]` (pivot), затем среди элементов справа выбираем максимальный, строго меньший `arr[pivot]`, и меняем их.

**Важно:**
- Разрешён только **один** обмен — разворот хвоста, как в «next permutation», недопустим
- Из подходящих элементов выбирается **максимальный** (чтобы перестановка была наибольшей из меньших)
- При дубликатах берётся **самый левый** из равных; в коде это выходит само — обновление идёт только при строгом `>`, поэтому первый найденный максимум сохраняется
- Если pivot не найден (массив неубывающий), возвращается исходный массив

## Сложность

- **Время:** `O(n)` — два прохода по массиву
- **Память:** `O(1)` — обмен на месте

## Примеры

| Вход | Выход |
|------|-------|
| `[3,2,1]` | `[3,1,2]` |
| `[1,1,5]` | `[1,1,5]` |
| `[1,9,4,6,7]` | `[1,7,4,6,9]` |
| `[3,1,1,3]` | `[1,3,1,3]` |
| `[1,2,3]` | `[1,2,3]` |
