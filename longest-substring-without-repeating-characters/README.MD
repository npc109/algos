# 3. Longest Substring Without Repeating Characters

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/longest-substring-without-repeating-characters/)  
**Темы:** String, Sliding Window, Hash Table

## Описание

Дана строка `s`. Вернуть длину самой длинной подстроки без повторяющихся символов.

**Важно:**
- Окно между `slow` и `fast` всегда содержит **уникальные** символы
- При встрече дубликата `slow` двигается вперёд, пока дубликат не уйдёт из окна
- `slow` и `fast` двигаются только вперёд — отсюда амортизированно `O(n)`, хотя внутри есть `while`
- Ветка `scur == cur` (дубликат — первый символ окна) позволяет сдвинуть оба указателя: `res = fast - slow`

## Сложность

- **Время:** `O(n)` — каждый символ добавляется в `Set` и удаляется не более одного раза
- **Память:** `O(min(n, k))`, где `k` — размер алфавита; `O(n)` в худшем случае (все символы уникальны)

## Примеры

| Вход | Выход |
|------|-------|
| `"abcabcbb"` | `3` |
| `"bbbbb"` | `1` |
| `"pwwkew"` | `3` |
| `"abcde"` | `5` |
| `"abba"` | `2` |
| `"tmmzuxt"` | `5` |
| `"abcabcabcd"` | `4` |
