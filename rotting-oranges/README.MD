# 994. Rotting Oranges

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/rotting-oranges/)  
**Темы:** Array, Matrix, BFS

## Описание

Дана матрица `grid` из `0` (пусто), `1` (свежий апельсин) и `2` (гнилой). Каждую минуту гнилые апельсины заражают свежих соседей по горизонтали и вертикали. Вернуть минимальное число минут, за которое сгниют все апельсины, или `-1`, если это невозможно.

**Важно:**
- Источников заражения может быть несколько — они работают одновременно
- Если свежих апельсинов нет — ответ `0`
- Метод изменяет входную матрицу

## Сложность

- **Время:** `O(m · n)` — каждая клетка попадает в очередь не более одного раза
- **Память:** `O(m · n)` — очередь в худшем случае

## Примеры

| Вход | Выход |
|------|-------|
| `[[2,1,1],[1,1,0],[0,1,1]]` | 4 |
| `[[2,1,1],[0,1,1],[1,0,1]]` | -1 |
| `[[0,2]]` | 0 |
| `[[1]]` | -1 |
| `[[2,1,1],[0,0,0],[2,1,1]]` | 2 |
| `[[2,0],[0,1]]` | -1 |
