# 230. Kth Smallest Element in a BST

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)  
**Темы:** Tree, DFS, Binary Search Tree, In-order

## Описание

Дан корень BST и число `k`. Вернуть `k`-й наименьший элемент (нумерация с 1).

**Важно:**
- In-order обход BST даёт значения по возрастанию
- Ответ можно вернуть **раньше**, не обходя правую часть дерева
- Ограничение задачи: `1 <= k <= n <= 10^4`, `0 <= Node.val <= 10^4`

## Сложность

- **Время:** `O(h + k)` — `h` шагов вниз до минимума плюс обход `k` узлов; `O(n)` в худшем
- **Память:** `O(h)` — стек рекурсии

## Примеры

| Вход | k | Выход |
|---|---|---|
| `[3,1,4,null,2]` | 1 | `1` |
| `[5,3,6,2,4,null,null,1]` | 3 | `3` |
| `[3,1,4,null,2]` | 4 | `4` |
| `[10,5,15,3,7,12,20,1]` | 1 | `1` |
