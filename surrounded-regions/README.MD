# 130. Surrounded Regions

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/surrounded-regions/)  
**Темы:** Array, Matrix, DFS, BFS, Union-Find

## Описание

Дана матрица `board` из `'X'` и `'O'`. Захватить все области `'O'`, полностью окружённые `'X'` — заменить такие `'O'` на `'X'`.

`'O'` **выживает**, если существует путь из неё до любой клетки на краю матрицы, проходящий только по `'O'` (4-соседство).

**Важно:**
- Клетка на краю всегда выживает
- Связность транзитивная: `'O'` в центре выживает, если соединена с краевой
- Метод изменяет матрицу на месте

## Сложность

- **Время:** `O(m · n)` — обход от краёв плюс финальный проход
- **Память:** `O(m · n)` — матрица посещённых и очередь

## Примеры

| Вход | Выход |
|------|-------|
| `[["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]` | `[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]` |
| `[["X"]]` | `[["X"]]` |
| `[["O"]]` | `[["O"]]` |
| `[["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","X","X","X"]]` | все `X` |
| `[["X","O","X"],["X","O","X"],["X","X","X"]]` | без изменений |
