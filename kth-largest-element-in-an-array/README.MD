# 215. Kth Largest Element in an Array

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/kth-largest-element-in-an-array/)  
**Темы:** Array, Heap (Priority Queue), Quickselect

## Описание

Дан массив чисел `nums` и число `k`. Вернуть `k`-й по величине элемент массива в отсортированном по убыванию порядке.

Min-heap размера `k`: каждый элемент добавляется в `PriorityQueue`, а при переполнении извлекается минимум — в куче остаются `k` наибольших, `peek()` и есть ответ.

**Важно:**
- Нужен `k`-й по величине, а не `k`-й **различный**: в `[7,7,7,7]` ответ `7`
- Проверка `num > peek()` перед вставкой не нужна: «всегда добавить, при переполнении выкинуть минимум» держит инвариант сам
- `1 <= k <= nums.length`, ответ существует всегда; `k == 1` — максимум, `k == n` — минимум
- Куча должна быть локальной переменной, иначе состояние утечёт между вызовами

## Сложность

- **Время:** `O(n log k)` — на каждый элемент вставка и не более одного извлечения
- **Память:** `O(k)` — куча на мгновение вырастает до `k + 1` элемента

## Примеры

| Вход | Выход |
|------|-------|
| `nums = [3,2,1,5,6,4], k = 2` | `5` |
| `nums = [3,2,3,1,2,4,5,5,6], k = 4` | `4` |
| `nums = [1], k = 1` | `1` |
| `nums = [7,7,7,7], k = 2` | `7` |
| `nums = [6,4,4,4,5], k = 4` | `4` |
