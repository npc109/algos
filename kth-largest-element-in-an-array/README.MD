# 215. Kth Largest Element in an Array

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/kth-largest-element-in-an-array/)  
**Темы:** Array, Heap (Priority Queue), Quickselect

## Описание

Дан массив целых чисел `nums` и число `k`. Вернуть `k`-й по величине элемент массива.

**Важно:**
- Нужен `k`-й по величине, а не `k`-й различный
- `1 <= k <= nums.length` — ответ существует всегда

## Алгоритм (Min-heap размера k)

Держим в куче ровно `k` наибольших элементов, увиденных к текущей позиции. Вершина min-heap — самый слабый из них, то есть искомый ответ после прохода.

1. Для каждого `num`: добавляем в `PriorityQueue` (в Java это min-heap)
2. Если размер кучи превысил `k` — извлекаем минимум `poll()`
3. Ответ — `peek()`

Проверка `num > peek()` не нужна: «всегда добавить, при переполнении выкинуть минимум» поддерживает инвариант автоматически.

## Визуализация

**Пример:** `nums = [6, 4, 4, 4, 5]`, `k = 4`

```
Вход:  [6, 4, 4, 4, 5], k = 4
       ↓
6 → [6]
4 → [4, 6]
4 → [4, 4, 6]
4 → [4, 4, 4, 6]        размер == k
5 → [4, 4, 5, 6]        5 добавили, выкинули вершину 4

Выход: 4
Отсортировано: [4, 4, 4, 5, 6], 4-й по величине — 4
```

## Сложность

- **Время:** `O(n log k)` — на каждый элемент вставка и не более одного извлечения
- **Память:** `O(k)` — куча не превышает `k + 1` элемента

## Примеры

| Вход | k | Выход |
|------|---|-------|
| `[3,2,1,5,6,4]` | 2 | 5 |
| `[3,2,3,1,2,4,5,5,6]` | 4 | 4 |
| `[1]` | 1 | 1 |
| `[7,7,7,7]` | 2 | 7 |
| `[6,4,4,4,5]` | 4 | 4 |
