# 213. House Robber II

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/house-robber-ii/)  
**Темы:** Dynamic Programming, Array

## Описание

Дома стоят **в круг**: первый и последний соседствуют. Нельзя обворовать два соседних дома. Вернуть максимальную сумму.

**Важно:**
- Сводится к двум задачам на **прямой**: дома `[0, n-2]` и дома `[1, n-1]`. Ответ — максимум из двух
- Три диапазона не нужны: вариант «не берём ни первый, ни последний» входит в оба случая
- При `n == 1` оба диапазона пустые (`[0, -1]` и `[1, 0]`) — нужна отдельная ветка с `nums[0]`
- При `n == 2` отдельная ветка **не** нужна: диапазоны дают `nums[0]` и `nums[1]`, а `max` берёт один из них, не сумму
- В отличие от 198, `[100,1,1,100]` даёт `101`, а не `200`: концы теперь соседи

## Сложность

- **Время:** `O(n)` — два прохода по `n`
- **Память:** `O(1)` — четыре переменные, по две на каждый проход

## Примеры

| Вход | Выход |
|------|-------|
| `nums = [2,3,2]` | `3` |
| `nums = [1,2,3,1]` | `4` |
| `nums = [1,2,3]` | `3` |
| `nums = [5]` | `5` |
| `nums = [5,6]` | `6` |
| `nums = [100,1,1,100]` | `101` |
