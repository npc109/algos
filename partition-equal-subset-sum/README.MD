# 416. Partition Equal Subset Sum

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/partition-equal-subset-sum/)  
**Темы:** Array, Dynamic Programming, 0/1 Knapsack

## Описание

Дан `nums` из натуральных чисел. Можно ли разбить его на два подмножества с равной суммой?

**Важно:**
- Нечётная сумма всех элементов — сразу `false`, до всякого DP
- Иначе задача сводится к 0/1 knapsack: набрать ровно `sum / 2`, каждый элемент не более одного раза
- Цикл по суммам идёт **вниз** от `target` до `n`: так `dp[i - n]` ещё относится к состоянию *до* обработки предмета, и элемент не берётся дважды
- Жадность не работает: `[8,7,6,5,4]` при жадном «берём крупные» даёт `false`, а разбиение есть (`8+7` и `6+5+4`)
- Память сжата с `O(n · target)` до `O(target)`: строка `dp` перезаписывается в памяти строк

## Сложность

- **Время:** `O(n · target)`, `target = sum / 2 <= 10000`. Худший случай — `200 · 10000 = 2·10^6`
- **Память:** `O(target)` — одномерный `boolean[]`

## Примеры

| Вход | Выход |
|------|-------|
| `nums = [1,5,11,5]` | `true` — `11` и `5+5+1` |
| `nums = [1,2,3,5]` | `false` |
| `nums = [1]` | `false` |
| `nums = [1,1]` | `true` |
| `nums = [8,7,6,5,4]` | `true` — `8+7` и `6+5+4` |
| `nums = [1,2,4]` | `false` — нечётная сумма |
