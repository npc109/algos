# 24. Swap Nodes in Pairs

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/swap-nodes-in-pairs/)  
**Темы:** Linked List, Recursion

## Описание

Дан связный список. Поменять местами каждые два соседних узла и вернуть голову результата; если узлов нечётное число — оставшийся узел остаётся на месте.

Рекурсия: новый хвост — `swapPairs` от третьего узла, второй узел становится головой и ссылается на первый.

**Важно:**
- Меняются сами узлы (`next`), а не значения `val` внутри них
- Нечётный хвост — терминальный случай: `head.next == null` возвращает `head` как есть
- Порядок операций: сохранить `n = head.next.next` **до** переподвязки, иначе хвост теряется
- Пустой список → `null`

## Сложность

- **Время:** `O(n)` — каждая пара обрабатывается один раз
- **Память:** `O(n)` — стек рекурсии глубиной `n / 2`

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,4]` | `[2,1,4,3]` |
| `[]` | `[]` |
| `[1]` | `[1]` |
| `[1,2,3]` | `[2,1,3]` |
