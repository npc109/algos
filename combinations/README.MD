# 77. Combinations

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/combinations/)  
**Темы:** Backtracking, Recursion

## Описание

Даны целые `n` и `k`. Вернуть все комбинации из `k` различных чисел диапазона `[1, n]`.

Backtracking: перебираем числа от `start` до `n`, кладём в текущий список, уходим рекурсией со стартом `i + 1` и откатываем последний элемент. При `size == k` в результат кладётся **копия** текущего списка.

**Важно:**
- В результат нужна копия (`new ArrayList<>(cur)`) — иначе все ответы будут ссылаться на один мутируемый список
- Следующая рекурсия стартует с `i + 1`: `start = i` даст перестановки и повторы, `start = 0` — дубликаты
- Числа в комбинации всегда возрастают, поэтому генерируется ровно `C(n, k)` цепочек
- Порядок комбинаций в ответе на LeetCode не проверяется

## Сложность

- **Время:** `O(k · C(n, k))` — столько комбинаций, каждая копируется за `O(k)`
- **Память:** `O(k)` — глубина рекурсии и текущий список, без учёта результата

## Примеры

| Вход | Выход |
|------|-------|
| `n = 4, k = 3` | `[[1,2,3],[1,2,4],[1,3,4],[2,3,4]]` |
| `n = 4, k = 2` | `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]` |
| `n = 1, k = 1` | `[[1]]` |
