# 77. Combinations

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/combinations/)  
**Темы:** Backtracking, Recursion

## Описание

Даны два целых числа `n` и `k`. Вернуть все возможные комбинации из `k` чисел, выбранных из диапазона `[1, n]`.

**Важно:**
- Каждая комбинация содержит ровно `k` уникальных чисел
- Комбинации идут в возрастающем порядке
- Порядок самих комбинаций значения не имеет (тест проверяет лексикографический)

## Алгоритм (Backtracking)

Классический поиск с возвратом:

1. **Базовый случай:** Если `cur.size() == k` — комбинация готова, добавляем копию в результат
2. **Рекурсивный шаг:**
   - Перебираем числа `i` от `start` до `n-1`
   - Добавляем `i + 1` в текущую комбинацию
   - Рекурсивно идём дальше со `start = i + 1` (числа не повторяются и идут по возрастанию)
   - **Откат (backtrack):** удаляем последний элемент `cur.removeLast()`

## Визуализация

**Пример:** `n = 4, k = 3`

```
[]
├── [1]
│   ├── [1,2]
│   │   └── [1,2,3] ✓
│   │   └── [1,2,4] ✓
│   └── [1,3]
│       └── [1,3,4] ✓
└── [2]
    └── [2,3]
        └── [2,3,4] ✓

Выход: [[1,2,3], [1,2,4], [1,3,4], [2,3,4]]
```

## Сложность

- **Время:** `O(k * C(n, k))` — C(n,k) комбинаций, каждая копируется за O(k)
- **Память:** `O(k)` — глубина рекурсии и текущая комбинация (без учёта результата)

## Примеры

| Вход | Выход |
|------|-------|
| `n = 4, k = 3` | `[[1,2,3], [1,2,4], [1,3,4], [2,3,4]]` |
| `n = 4, k = 2` | `[[1,2], [1,3], [1,4], [2,3], [2,4], [3,4]]` |
| `n = 1, k = 1` | `[[1]]` |
