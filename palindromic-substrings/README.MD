# 647. Palindromic Substrings

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/palindromic-substrings/)  
**Темы:** String, Dynamic Programming

## Описание

Дана строка `s`. Вернуть число подстрок, являющихся палиндромами. Подстроки с одинаковым содержимым в разных позициях считаются отдельно.

**Важно:**
- Состояние: `dp[i][j]` — является ли `s[i..j]` палиндромом
- Переход: `s[i] == s[j] && dp[i + 1][j - 1]` — **внутренний** отрезок
- Порядок обязателен: внешний цикл **по длине**, иначе `dp[i+1][j-1]` к моменту `dp[i][j]` ещё не посчитана. При порядке по `i`: для `"abcba"` ячейка `dp[0][4]` читает `dp[1][3]`, а строка `i = 1` обработается только после всей строки `i = 0`
- Ошибка видна не на всех входах: `"aaa"` даёт верный ответ и при неправильном порядке, так как `dp[i+1][i+1]` — база. Ломается только вложенный палиндром (`"abcba"`: `6` вместо `7`, `"aaaa"`: `9` вместо `10`)
- Длина 2 проверяется **без** `dp[i+1][j-1]`: `dp[i+1][i]` — пустой отрезок
- Каждая пара `(l, r)` при `l <= r` задаёт ровно одну подстроку, поэтому счётчик увеличивается на 1 на каждый найденный палиндром

## Сложность

- **Время:** `O(n²)` — `n(n+1)/2` отрезков, каждый за `O(1)`
- **Память:** `O(n²)` — `boolean[n][n]`; заполняется только верхний треугольник
- **Альтернатива:** расширение от центра за `O(n²)` времени и `O(1)` памяти

## Примеры

| Вход | Выход |
|------|-------|
| `s = "abc"` | `3` |
| `s = "aaa"` | `6` |
| `s = "aa"` | `3` |
| `s = "aaaa"` | `10` |
| `s = "abcba"` | `7` |
| `s = "abacdfgdcaba"` | `14` |
| `s = "a"×1000` | `500500` |
