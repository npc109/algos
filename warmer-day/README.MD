# 739. Daily Temperatures (Warmer Day)

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/daily-temperatures/)  
**Темы:** Array, Stack, Monotonic Stack

## Описание

Дан массив `temperatures`. Для каждого дня вернуть, через сколько дней наступит более тёплый день; если такого дня нет — `0`.

Монотонный стек индексов: пока стек не пуст и температура текущего дня выше, для вершины стека найден ответ `i - cur`, и она извлекается. Текущий индекс кладётся в стек.

**Важно:**
- «Более тёплый» — **строго** больше: условие `temperatures[peek] < t`, а не `<=`. Иначе равная температура засчитается как потепление
- В ответ пишется **разница индексов** `i - cur`, а не индекс и не значение
- Оставшиеся в стеке дни ответ не получают — `res` инициализирован нулями
- Пустой массив → пустой массив

## Сложность

- **Время:** `O(n)` — каждый индекс кладётся и извлекается не более одного раза
- **Память:** `O(n)` — стек в худшем случае (температуры убывают)

## Примеры

| Вход | Выход |
|------|-------|
| `[73,74,75,71,69,72,76,73]` | `[1,1,4,2,1,1,0,0]` |
| `[30,40,50,60]` | `[1,1,1,0]` |
| `[70,60,50,40]` | `[0,0,0,0]` |
| `[50,50,50]` | `[0,0,0]` |
| `[50]` | `[0]` |
| `[55,50,50,60]` | `[3,2,1,0]` |
