# 739. Daily Temperatures (Warmer Day)

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/daily-temperatures/)  
**Темы:** Array, Stack, Monotonic Stack

## Описание

Дан массив ежедневных температур. Для каждого дня найти, сколько дней нужно подождать до более тёплого дня. Если более тёплого дня нет — поставить `0`.

**Важно:**
- «Более тёплый» — строго больше (`<`, а не `<=`): одинаковая температура не считается
- Ответ — не индекс, а **разница в днях** (`i - cur`)

## Алгоритм (Monotonic Stack)

Храним в стеке индексы дней, для которых ещё не нашли более тёплый день. Стек монотонно убывающий по температуре.

Для каждого нового дня `i` с температурой `t`:

1. **Пока** стек не пуст и `temperatures[s.peek()] < t`:
   - извлекаем `cur = s.pop()` — для дня `cur` текущий день `i` и есть первый тёплый
   - записываем `res[cur] = i - cur`
2. **Толкаем** `i` в стек (`s.push(i)`)

Дни, оставшиеся в стеке после прохода, ответ не получают — для них потепления не было (`res` по умолчанию `0`).


Каждый индекс попадает в стек ровно один раз и один раз извлекается — отсюда линейная сложность.

## Сложность

- **Время:** `O(n)` — каждый элемент добавляется и извлекается из стека не более одного раза
- **Память:** `O(n)` — стек в худшем случае (температуры убывают)
