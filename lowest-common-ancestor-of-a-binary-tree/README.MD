# 236. Lowest Common Ancestor of a Binary Tree

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)  
**Темы:** Tree, DFS, Post-order

## Описание

Дано бинарное дерево (не BST) и два узла `p` и `q`. Вернуть наименьшего общего предка — самого глубокого узла, который является предком обоих.

**Важно:**
- Дерево не упорядочено, поэтому по значению нельзя сказать, куда идти — обход всегда `O(n)`
- Узел считается предком **самого себя**: если `p` в поддереве `q`, ответ `q`
- Ответ возвращается **наверх через возврат**, а не передаётся вниз параметром
- Если `p` найден слева, а `q` справа — текущий узел и есть LCA

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — стек рекурсии; `O(n)` в худшем случае

## Примеры

Дерево: `[3,5,1,6,2,0,8,null,null,7,4]`

| p | q | Выход |
|---|---|---|
| 5 | 1 | `3` |
| 5 | 4 | `5` |
| 6 | 4 | `5` |
| 7 | 4 | `2` |
| 0 | 8 | `1` |
