# 236. Lowest Common Ancestor of a Binary Tree

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)  
**Темы:** Tree, DFS, Post-order

## Описание

Дано бинарное дерево (**не BST**) и два узла `p` и `q`. Вернуть их **наименьшего общего предка** — самого глубокого узла, который является предком и для `p`, и для `q`.

Узел считается предком **самого себя** — поэтому если `p` лежит в поддереве `q`, ответ `q`.

## Почему это не BST-задача

Дерево не упорядочено, поэтому **нельзя по значению сказать, куда идти**. Значит обход всегда `O(n)` — в отличие от Validate BST, где диапазон отсекал половину.

## Алгоритм (post-order)

Функция `dfs(node)` возвращает **что нашла** в своём поддереве:

| `left` | `right` | Что это значит | Вернуть |
|---|---|---|---|
| `null` | не `null` | найден только один, в правом | `right` |
| не `null` | `null` | найден только один, в левом | `left` |
| **не `null`** | **не `null`** | **один слева, другой справа** | **`node`** ← LCA |
| `null` | `null` | ни одного | `null` |

Плюс проверка в начале: если `node == p` или `node == q` → вернуть `node` (дальше не искать: узел является предком самого себя).

**Почему `node` — ответ в третьем случае:** если `p` нашлась слева, а `q` справа, то `node` — **единственный** узел, являющийся предком обоих. Левее не предок `q`, правее не предок `p`.

**Почему дальше не меняется:** родитель `node` увидит «слева непусто, справа пусто» и вернёт **левое** — то есть тот самый `node`. Ответ поднимается наверх неповреждённым.

## Ключевой принцип

**Ответ идёт наверх через возврат, а не вниз через параметр.**

Первый вариант решения использовал параметр `already`, который тащил результат **вниз** — это тот же паттерн ошибки, что «накопитель-параметр вместо возврата» (LIS, Max Area, Diameter).

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — стек рекурсии; `O(n)` в худшем случае (вырожденное дерево)

## Проверка

17 тестов, включая сверку **всех пар узлов** с эталоном, построенным **по определению** (списки предков от корня). Ручные ожидания в этом тесте не используются — они ошибались 9 раз за сессию.

## Примеры

Дерево:
```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

| p | q | Выход |
|---|---|---|
| 5 | 1 | `3` |
| 5 | 4 | `5` |
| 6 | 4 | `5` |
| 7 | 4 | `2` |
| 0 | 8 | `1` |
