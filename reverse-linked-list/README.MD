# 206. Reverse Linked List

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/reverse-linked-list/)  
**Темы:** Linked List, Iteration

## Описание

Дан односвязный список. Развернуть его и вернуть новую голову.

Итеративно: `node` — уже развёрнутая часть (изначально `null`), на каждом шаге сохраняем `head.next` в `tmp`, разворачиваем ссылку `head.next = node` и сдвигаем оба указателя.

**Важно:**
- Возвращается `node`, а не `head`: к концу цикла `head == null`
- `head.next` надо перезаписать только после сохранения в `tmp`, иначе хвост теряется
- Пустой список → `null`, список из одного узла → он же: цикл обрабатывает оба случая без особых проверок
- Меняется структура ссылок, а не значения `val`

## Сложность

- **Время:** `O(n)` — один проход по списку
- **Память:** `O(1)` — три указателя, список меняется на месте

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,4,5]` | `[5,4,3,2,1]` |
| `[1,2]` | `[2,1]` |
| `[]` | `[]` |
| `[1]` | `[1]` |
