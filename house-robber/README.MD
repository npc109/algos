# 198. House Robber

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/house-robber/)  
**Темы:** Array, Dynamic Programming

## Описание

Дан массив `nums`, где `nums[i]` — деньги в доме `i`. Нельзя грабить два соседних дома. Вернуть максимальную сумму.

**Важно:**
- Соседними считаются дома с индексами `i` и `i+1`
- Пустой массив — допустимый вход (ответ `0`)
- Числа неотрицательные

## Алгоритм (1D DP с O(1) памяти)

Состояние: `dp[i]` — максимум для первых `i+1` домов.

Переход: `dp[i] = max(dp[i-1], nums[i] + dp[i-2])` — либо не грабим дом `i`, либо грабим его и берём лучшее для `i-2`.

В коде хранятся только два предыдущих значения: `prev1` = `dp[i-1]`, `prev2` = `dp[i-2]`.

## Сложность

- **Время:** `O(n)` — один проход
- **Память:** `O(1)` — две переменные вместо массива

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,1]` | 4 |
| `[2,7,9,3,1]` | 12 |
| `[5]` | 5 |
| `[]` | 0 |
| `[2,7,1]` | 7 |
| `[2,1,1,2]` | 4 |
| `[100,1,1,100]` | 200 |
