# 198. House Robber

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/house-robber/)  
**Темы:** Array, Dynamic Programming

## Описание

Дан массив `nums`, где `nums[i]` — деньги в доме `i`. Нельзя грабить два соседних дома. Вернуть максимальную сумму.

1D DP: `dp[i] = max(dp[i-1], nums[i] + dp[i-2])` — либо пропускаем дом, либо берём его вместе с лучшим результатом через один. В коде хранятся только `prev1` и `prev2`.

**Важно:**
- Соседними считаются только `i` и `i+1`; дома через один грабить можно
- Пустой массив даёт `0` — обе переменные стартуют с `0`, отдельный случай не нужен
- Обновлять `prev2 = prev1` нужно **до** перезаписи `prev1` (в коде — через `tmp`)
- Значения неотрицательны, поэтому «ничего не взять» никогда не хуже отрицательного дома

## Сложность

- **Время:** `O(n)` — один проход по массиву
- **Память:** `O(1)` — две переменные вместо массива `dp`

## Примеры

| Вход | Выход |
|------|-------|
| `[1,2,3,1]` | `4` |
| `[2,7,9,3,1]` | `12` |
| `[5]` | `5` |
| `[]` | `0` |
| `[2,7,1]` | `7` |
| `[2,1,1,2]` | `4` |
| `[100,1,1,100]` | `200` |
