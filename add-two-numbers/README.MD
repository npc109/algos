# 2. Add Two Numbers

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/add-two-numbers/)  
**Темы:** Linked List, Math, Recursion

## Описание

Даны два непустых связных списка, представляющих два неотрицательных целых числа. Числа хранятся в обратном порядке — каждая цифра записана в отдельном узле. Необходимо сложить два числа и вернуть результат в виде связного списка.


## Примеры

| Вход (l1) | Вход (l2) | Выход |
|-----------|-----------|-------|
| `[2,4,3]` | `[5,6,4]` | `[7,0,8]` |
| `[0]` | `[0]` | `[0]` |
| `[9,9,9,9,9,9,9]` | `[9,9,9,9]` | `[8,9,9,9,0,0,0,1]` |
