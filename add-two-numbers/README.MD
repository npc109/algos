# 2. Add Two Numbers

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/add-two-numbers/)  
**Темы:** Linked List, Math, Recursion

## Описание

Даны два связных списка, представляющих неотрицательные числа в **обратном порядке** (младшая цифра в голове). Сложить их и вернуть результат в виде связного списка в том же порядке.

**Важно:**
- Списки разной длины: когда один кончился, продолжаем со вторым
- Перенос `carry` может остаться после последнего узла — нужен дополнительный узел
- Числа не помещаются в `int`/`long`, поэтому складывать нужно поразрядно

## Сложность

- **Время:** `O(max(m, n))` — один проход по обоим спискам
- **Память:** `O(max(m, n))` — новый список результата

## Примеры

| Вход (l1) | Вход (l2) | Выход |
|-----------|-----------|-------|
| `[2,4,3]` | `[5,6,4]` | `[7,0,8]` |
| `[0]` | `[0]` | `[0]` |
| `[9,9,9,9,9,9,9]` | `[9,9,9,9]` | `[8,9,9,9,0,0,0,1]` |
