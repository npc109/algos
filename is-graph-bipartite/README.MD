# 785. Is Graph Bipartite?

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/is-graph-bipartite/)  
**Темы:** Graph, DFS, BFS, Union-Find

## Описание

Дан неориентированный граф списком смежности `graph`, где `graph[u]` — соседи вершины `u`. Вернуть `true`, если граф двудольный: вершины можно раскрасить в два цвета так, чтобы никакие две соседние не имели одинаковый цвет.

**Важно:**
- Граф двудольный тогда и только тогда, когда в нём нет циклов нечётной длины
- Граф может быть несвязным — нужен внешний цикл по всем компонентам
- Петли и повторяющиеся рёбра исключены условием

## Сложность

- **Время:** `O(V + E)` — каждая вершина и каждое ребро обрабатываются один раз
- **Память:** `O(V)` — массив цветов и стек рекурсии

## Примеры

| graph | Выход |
|---|---|
| `[[1,2,3],[0,2],[0,1,3],[0,2]]` | false |
| `[[1,3],[0,2],[1,3],[0,2]]` | true |
| `[[1],[0]]` | true |
| `[[]]` | true |
| `[[2],[2],[0,1]]` | true |
| `[[1],[0],[3,4],[2,4],[2,3]]` | false |
| `[[1,2],[0,2],[0,1]]` | false |
