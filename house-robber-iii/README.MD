# 337. House Robber III

**Сложность:** Medium  
**Источник:** [LeetCode](https://leetcode.com/problems/house-robber-iii/)  
**Темы:** Tree, Depth-First Search, Dynamic Programming

## Описание

Дома — узлы бинарного дерева. Нельзя обворовать узел и его прямого родителя или ребёнка. Вернуть максимальную сумму.

**Важно:**
- `dfs(node)` возвращает **два** значения: `[0]` — максимум в поддереве, если `node` взят; `[1]` — если не взят
- Взяли узел → дети не взяты: `[0] = node.val + left[1] + right[1]`
- Не взяли узел → детей можно брать и не брать: `[1] = max(left[0], left[1]) + max(right[0], right[1])`
- `null` → `{0, 0}`
- Ответ — `max(root[0], root[1])`
- Считать по **уровням** нельзя: узлы разных уровней могут быть несвязанными, и запрет действует только на пару «родитель — ребёнок». Пример `[3,4,5,1,3,null,1]`: по уровням выходит `7`, а правильно `9` (`4 + 5`)
- Накопитель, спускаемый вниз (`state` в аргументах), ломает решение: значения должны возвращаться снизу вверх

## Сложность

- **Время:** `O(n)` — каждый узел посещается один раз
- **Память:** `O(h)` — глубина рекурсии, `h` — высота дерева; `O(n)` в вырожденном случае
- **Мемоизация не нужна**: каждый узел имеет одного родителя, повторных вычислений нет

## Примеры

| Вход | Выход |
|------|-------|
| `[3,2,3,null,3,null,1]` | `7` — `3 + 3 + 1` |
| `[3,4,5,1,3,null,1]` | `9` — `4 + 5` |
| `[1,2,3]` | `5` — `2 + 3` |
| `[4,1,null,2,null,3]` | `7` — цепочка `4-1-2-3`, оптимум `4 + 3` |
| `[0]` | `0` |
