# 127. Word Ladder

**Сложность:** Hard  
**Источник:** [LeetCode](https://leetcode.com/problems/word-ladder/)  
**Темы:** BFS, Hash Table, String

## Описание

Даны `beginWord`, `endWord` и `wordList`. За шаг меняется ровно одна буква, результат обязан быть в `wordList`. Вернуть длину кратчайшей цепочки (число слов, включая оба конца) или `0`.

**Важно:**
- Ответ — **число слов**, не шагов: `hit→hot→dot→dog→cog` = 4 шага, но **5** слов
- Соседи неявные: менять буквы и проверять через `HashSet`, а не сравнивать слова попарно
- Соседей генерировать **лениво, по ходу BFS** — построение всего графа заранее дороже, если путь короткий
- Посещённое помечать **при добавлении в очередь** (`visited.add` возвращает `boolean`), иначе дубликаты
- После перебора букв вернуть исходную: `ca[pos] = old`

## Сложность

- **Время:** `O(V · L² · 26)`, где `V` — число посещённых слов; `L²` из создания строки и хеширования
- **Память:** `O(n)` — очередь и `visited`, граф не хранится

## Примеры

| begin | end | wordList | Выход |
|---|---|---|---|
| `hit` | `cog` | `["hot","dot","dog","lot","log","cog"]` | `5` |
| `hit` | `cog` | `["hot","dot","dog","lot","log"]` | `0` |
| `hot` | `dot` | `["dot"]` | `2` |
| `a` | `c` | `["b","c"]` | `2` |
| `hit` | `cog` | `["xxx","yyy","cog"]` | `0` |
